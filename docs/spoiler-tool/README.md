# Expedition 33 — Spoiler Codex

The spoiler codex is generated by the build. Every `rebuild-mod` / standalone generator
`rebuild-mod` run builds a fresh, single-file HTML spoiler for the seed it just
packed:

```
Export/Spoilers/ExpeditionInfinity_<seed>_Spoiler.html
```

That one file is the hand-off artifact. It contains the HTML, CSS, JavaScript
and the full seed payload; there is no companion JSON, no Python script and no
server requirement. A player can open it directly from `file://`.

## What it contains

| Section | Contents |
|---|---|
| **Nevrons** | Every enemy row by area. Effective in-fight HP / ATK / SPD / XP / Chroma, all `EnemyScaling` multipliers, raw `EnemyStats`, location, encounter rows and every seed drop with its percentage. |
| **Chests** | The seed's `DT_ChestsContent` rows grouped by area. Each chest lists its direct item slots and chances; upgrade-table references are marked as rolls. |
| **Pictos** | Stat multipliers, Chroma multiplier, Lumina cost, master-battles, descriptions and seed chest / Nevron sources. T1–T5 bands from the randomizer catalog. |
| **Chroma** | Chroma Pack source table plus Chroma-per-kill ranking for the seed. |
| **Key Items** | Quest keys, inks, cakes, unlocks and story objects, with descriptions and known fixed sources. |
| **Tints** | Consumable healing / energy / revive / party tints and their tint shards. |
| **Weapons** | The seed's rolled owner, damage element, free-aim element, base multipliers, Chroma multiplier, attribute scaling grades and all five level passives. |
| **All Items** | The full item catalogue with category filters (pictos, weapons, key items, cosmetics, catalysts, music, journals, feet, DLC, cut content). |

### Dataset switch

The top bar switches **Nevron data** between:

- **Seed `<n>`** — the staged `work/mod` tables from the pack just built.
- **Vanilla** — the original `work/enemies.json` rows, for comparison.

Drop/source lists always use the seed's staged chest and enemy tables. The
vanilla dataset is only the enemy-stat comparison.

### Cut content

Cut content is hidden by default. Use **Show cut content** to include
placeholder rows, test enemies, broken items and unreleased DLC/quest content.

## Regenerating

Normal workflow: run:

```bash
dotnet src/E33ModEditor.Cli/bin/Release/net10.0/E33ModEditor.Cli.dll rebuild-mod
```

Both paths stage the seed and build the spoiler after the randomizer has run.

For a generator-only check from the current `work/mod` stage:

```bash
dotnet src/E33ModEditor.Cli/bin/Release/net10.0/E33ModEditor.Cli.dll spoiler-build 42
# optional: --out path/to/file.html
```

The generator lives in
`src/E33ModEditor.Core/Spoiler/SpoilerCodexKit.cs`; the single-file template is
`src/E33ModEditor.Core/Spoiler/template.html` (embedded as a resource).

## Stat method

Effective HP / attack / speed / XP / Chroma are computed as:

```
archetype[level] × EnemyScaling[field]
```

This mirrors `FL_EnemyScalingHelpers.ComputeCharacterStats`, which is what the
game actually reads. Raw `EnemyStats` values are shown beside them because
many late-game rows carry placeholders (`HP 1`, `ATK 0`) in the table.

Seed defense uses the staged neutral `1.0` defense base from
`EnemyDefenseKit`; vanilla archetype defense bases are zero.

## Notes

- Old seed spoilers are intentionally kept. The pack cleaner removes old
  `ExpeditionInfinity_*_P` trios, but the spoiler files are small and useful
  for hosting several seeds.
- The spoiler is generated after the randomizer and all late loot pins, but
  before the IoStore pack. If spoiler generation fails, the pack still ships
  and the pack log records `[spoiler] failed: …`.
