# Spoiler codex fonts

These three fonts are embedded into every generated spoiler HTML so the file
renders identically offline, without Google Fonts or a local font install.

- **Cinzel** — SIL Open Font License 1.1
- **EB Garamond** — SIL Open Font License 1.1
- **Bebas Neue** — SIL Open Font License 1.1

They match the Expedition Infinity guide's design system
(`docs/Expedition Infinity Guide/palette.json`).
